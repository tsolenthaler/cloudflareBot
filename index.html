🔑 Cloudflare API-Token konfigurieren

Dein API-Token wird ausschließlich lokal im Browser gespeichert und niemals an einen Server übertragen.

📚 So erhältst du deinen API-Token:
1. Gehe zu Cloudflare Dashboard → Profile → API Tokens
2. Klicke auf "Create Token"
3. Wähle eine Vorlage oder erstelle einen benutzerdefinierten Token
4. Stelle sicher, dass der Token die benötigten Berechtigungen hat:
   • Zone:Read, DNS:Edit, Zone Settings:Edit
⚠️ CORS-Problem:
Browser blockieren direkte API-Aufrufe an Cloudflare (CORS-Policy).
Lösungen:
1. Browser-Extension: Installiere "CORS Unblock" (nur für Tests)
2. CORS-Proxy: CORS-Proxy aktivieren (⚠️ Token läuft über Drittanbieter-Server!)
3. Cloudflare Worker: Sicherste Lösung - eigenen Proxy erstellen
