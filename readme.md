# Facts

Name des Bots "CloudflareHelper".
Einen AI Bot der via WebChat bei Claudflare der die Verwaltung mehere Accounts, Domains, DNS und Rules macht.

## Domain
* Domains erstellen und bearbeiten
* Mehrer Domains hinzüfgen und bearbeiten
* direkt Link zur Domain in Cloudflare

## DNS
* DNS von Domains erstellt / importiert und editiert
* Mehere Domains können hinzugefügt und bearbeitet werden
* Direkt link direkt zu dem DNS-Eintrag der Domain in Cloudflare

## Rules
* Auflisten aller Regeln pro Domain
* Mehere Weiterleitung können pro Domain eingerichtet werden.
* Verlinkt direkt zur Regel der Domain in Cloudflare

## Funktionen
* Der API-Token von Cloudflare soll offline nur auf genutzt Browser gespeichert werden.
